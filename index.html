    Folders

    Documents

    PDF, .txt or .md, stored only on this phone. Start each file with a line like SOURCE: FCOM Vol 1 | REV: 47, or set the name and revision after adding it.

    Pages that are pictures (scans) or contain diagrams and tables are read by Gemini, or by Claude if you have no Gemini key. You'll see the page count and cost first.

    🌐 Add a web source

    For big documents that live on a website, like the CARs. Nothing is downloaded. When a run uses this folder, Claude searches only that site, quotes the exact sections and links them.

    Image bank

    Images you've saved from finished runs, for this library. The Director reuses a matching one instead of paying to draw a new one, and you can pick them in the plan.

    Reference photos

    Your own photos or screenshots. ChatGPT redraws from them so layouts are accurate. Name them by what they show. They go into the folder chosen above.

    API keys

    Saved only in this browser on this phone. Each service bills you directly, pay-as-you-go.

    Test connections checks keys and model names for free. Full system check runs one tiny real job for every feature (writing, caching, web search, CARs-style site lookup, images, narration, research) and tells you exactly what works. It costs about $1, mostly the two test images and the CARs lookup.

    Deck design

    Upload your airline's PowerPoint template (.pptx or .potx). Echelon takes its colours, fonts, background images and logo and uses them on every deck it builds. It copies the look of your slide masters, but doesn't load the masters themselves.

    Spending

    0 means no cap. A stopped run keeps its progress, so you can raise the cap and resume. Amounts are estimates from each service's usage reports. Your provider dashboards show the exact bill.

    Prices used for estimates

    USD per million tokens [input, output, image input]. Add or change models here if prices change.

    Backup and restore

    Your libraries, projects and rules are stored only in this browser. Save a backup file regularly (to Drive or by email), and always before clearing Chrome's data or changing phones.

    Team rules

    Standing instructions every team follows. Added from "Teach the team" or here.
