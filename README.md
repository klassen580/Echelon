# Echelon

One intelligence. Many minds. Working in harmony.

Echelon (formerly Auriga) is a single-file web app that runs Claude, ChatGPT, Gemini and Perplexity as a team. Hosted page: https://klassen580.github.io/Echelon/

API keys, the library and history are stored only in your own browser. Nothing private is in this repository.
